## 解读范围

这是在第 3 轮已按开发验证集选定并完成测试之后，按用户要求增加的事后核验。原先选择记录及模型权重保持不变；本补测没有重新训练、改标签或改划分。

该对照描述这份固定测试集上的结果，不把同一场景或采集组内的问题视为独立样本，也不据此声称统计显著或保证其他分布上的排序。

验证与测试的任务比例不同：车辆消息任务占验证集约 10.7%，占测试集约 30.7%。因此总体准确率的跨集合下降不能直接等同于过拟合；这里同时核对按任务、按类别平衡后的指标。
