# SecJev-9B 训练与评测结果

官方 Kev-9B → SecJev-Corpus 三轮。训练使用全部 9 张 GPU。使用 LoRA r16 和决策头，BF16 冻结骨干、FP32 LoRA/决策头/优化器，BF16 混合精度训练；评测使用 BF16 骨干、FP32 LoRA 和决策头。

本次三轮训练和全部评测均已完成。训练耗时约 **14 小时 14 分钟**，自动评测约 **2 小时 28 分钟**。结束后已核实九张 GPU 均无计算进程、利用率为 0%。本次发布采用开发集选出的第 3 轮。

安全测试覆盖 **21,634 题、14 项任务**，不是抽样结果。任务宏平均准确率对 14 项任务等权平均；任务宏平均平衡准确率先对每项任务内的语义类别召回率求平均，再对任务等权平均。

开发验证集选择第 3 轮；三个 checkpoint 均按预定方案测试，测试集不用于选择。

## 开发集选择与校准

选择依据为 14,912 题开发集的任务宏平均平衡准确率；相同分数时比较任务宏平均原始 NLL，再优先较早轮次。温度只使用另行划分的 14,821 题校准集拟合，随后冻结模型与温度，才运行安全测试集。

| 轮次 | 开发集总准确率 | 开发集任务宏平均准确率 | 开发集任务宏平均平衡准确率 | 校准温度 |
|---|---:|---:|---:|---:|
| 1 | 89.55% | 92.83% | 90.14% | 1.319186 |
| 2 | 90.60% | 93.86% | 91.54% | 1.181038 |
| 3 | 90.98% | 94.02% | 92.22% | 1.242444 |

第 3 轮的安全测试总准确率比官方 Kev-9B 高 **37.24 个百分点**，任务宏平均高 **24.69 个百分点**。通用 clean 准确率分别下降 **0.17** 和 **0.30 个百分点**，在这两项测试中基本保留原有能力。安全任务中，VeReMi 的两项准确率仍只有 **71.39%** 和 **68.53%**，是当前主要短板。

## 完整性核对

已逐项核对每轮开发、校准和安全测试的唯一 `(case, qid)` 数量、标签与原始数据一致性、分片与合并输出一致性；重新计算了总准确率、14 项分任务指标和两种任务宏平均，与报告一致。全部相关推理、训练、评测与报告步骤退出码为 0，模型选择符合预定开发集规则。

通用基准按唯一记录 ID 和题目 ID 核对。原基准含内容相同的对照请求：decision-v7 有 6 对原题/不改变顺序的置换题，transfer-v4 有 1 对此类置换题及 24 对 relevant/irrelevant 对照中的相同起始请求。保留官方基准语义和计分方式，没有据此增删测试题；不同记录 ID 不代表内容完全独立。
